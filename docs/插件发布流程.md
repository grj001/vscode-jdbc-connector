# 插件发布流程

## 1. 准备发布版本

- 确认功能已完成并通过本地验证
- 检查 `README.md`、`package.json`、图标、文档是否已同步更新
- 确认版本号已按语义化版本号递增

## 2. 更新扩展元数据

- 修改 `package.json` 中的 `version`
- 检查 `publisher` 是否已配置为正确的发布者
- 确认 `displayName`、`description`、`categories`、`keywords` 等信息准确

## 3. 本地打包检查

```bash
npm install
npm run compile
npm run package
```

打包后会生成 `.vsix` 文件，可用于本地安装验证。

## 4. 本地安装验证

在 VS Code 中安装生成的 `.vsix` 文件，确认：

- 扩展可以正常激活
- 侧边栏视图正常显示
- 连接配置、查询、结果视图功能可用
- 无明显报错或控制台异常

## 5. 登录发布账号

```bash
npx @vscode/vsce login <publisher>
```

根据提示完成账号授权。

## 6. 发布到 Marketplace

```bash
npx @vscode/vsce publish
```

如果需要指定版本，也可以先更新 `package.json` 后再发布。

## 7. 发布后检查

- 确认 Marketplace 页面信息正确
- 安装最新版本进行回归验证
- 记录本次发布版本与变更内容
